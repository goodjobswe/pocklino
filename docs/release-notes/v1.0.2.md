# Pocklino 1.0.2

QR sharing now sends the same page in far simpler codes, and fewer of them. Install this version on both devices before passing a page by QR.

## What changed

- The page is compressed before it goes into the QR, and the code uses a denser QR mode. An ordinary page of text needs less than half the QR capacity it did before.
- No code is denser than 57 by 57 squares. In 1.0.1 every animated frame was 77 by 77.
- A long page is cut into equal pieces, so a shorter page gets even plainer codes.
- The code is larger on a wide window, which helps when a phone reads it from a computer monitor.
- **Enlarge code** now works for animated codes too. The button sits beside the frame controls, and the code keeps playing while enlarged.
- The camera looks for a code about five times as often, so each frame of a moving code gets several attempts.
- Copied codes and `.pocklino` files are unchanged.

## Older versions

Version 1.0.2 still reads QR codes shown by 1.0.0 and 1.0.1. Those versions cannot read the new QR codes, so update both the device that shows the code and the device that scans it. Copied codes and files work between all versions.

## Install

**Android:** download `pocklino-v1.0.2.apk`, open it on your phone and allow installation from the browser or file manager if asked. Requires Android 6.0 or newer. It updates version 1.0.0 or 1.0.1 in place and keeps your notes.

**Windows:** download `pocklino-v1.0.2-windows.zip`, extract the whole archive, then run `pocklino.exe`. Keep the DLLs and `data` folder beside it. The ZIP includes the Visual C++ runtime. Windows can display QR codes and receive files or pasted codes; camera scanning is available on Android.

## Try this

Open a long page on the computer, choose **Pass** and scan it with the phone. Try the normal size first, then **Enlarge code**. Move the speed slider toward Faster and see how far it can go before pieces are missed.

Scanning with a real camera has not been tested for this version. It depends on the camera, focus, distance and screen brightness; please report what works and what does not.

## Validation

Static analysis is clean and all 63 Flutter tests pass, including the new format, damaged and altered codes, codes from earlier versions and a size limit on decompression. 20 rendered QR images on phone, narrow phone and desktop layouts decode to their expected content with the bundled reader. In the web build, a second browser reads a scanned code and previews the page.
