Pocklino is a small notebook for thoughts, groceries, films, trips and little surprises. This is the first release.

- Five kinds of page, each its own paper: a note slip, a checklist receipt, a cinema ticket, a luggage tag for a trip and an envelope for a letter.
- Collections, pinning, search, filters and an archive.
- Letters with **Open later**, which keeps the envelope sealed until a date and time you choose.
- Pass a copy of a page by QR code, by a copied code or as a `.pocklino` file. The receiver sees a preview before keeping it.
- A day look and an evening look.
- Everything stays on your device: no account, no server, no analytics and no advertising. Export a backup from Settings to keep a copy.

**Android:** download `pocklino-v1.0.0.apk` below and open it on the phone. Android asks once to allow installs from that source. It needs Android 6.0 or newer.

**Windows:** download `pocklino-v1.0.0-windows.zip`, extract the whole archive and run `pocklino.exe`. The app is not code signed, so Windows may show a warning the first time; choose **More info** and **Run anyway**. Windows has no camera scanning: receive a page by file or by pasting its code.

A SHA-256 checksum is included beside each file.

Good to know: passing a page makes an independent copy and nothing syncs afterwards. Open later is a friendly surprise based on the device's clock, not a lock, and notes are not encrypted.
